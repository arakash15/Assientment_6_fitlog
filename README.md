# 💪 FitLog — Workout Library

A dark, no-nonsense gym companion: browse lifts, lock them into today's plan, and track the totals.

## Technologies
Next.js (App Router), React, Tailwind CSS v4, lucide-react, deployed on Vercel.

## Features
- Responsive hero + 3-column library grid fed by the FitLog API (with fallback API)
- Sort by duration, calories or rating
- Detail page with specs, instructions, Add to plan / Save for later and toasts
- My Plan page with live Exercises / Minutes / Calories metrics and Today's Plan / Saved tabs
- Mark as Done and Remove actions, 5-lift plan cap, localStorage persistence
- Custom 404 page and loading states

## Run
`npm install && npm run dev`
